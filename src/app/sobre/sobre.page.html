Sobre a disciplina

A disciplina de desenvolvimento front-end tem como objetivo ensinar os conceitos básicos de criação de interfaces para aplicações web e mobile. Durante as aulas, são abordadas tecnologias como HTML, CSS e frameworks modernos, como o Ionic, que permitem o desenvolvimento de aplicativos híbridos.

Este projeto foi desenvolvido como parte das atividades da disciplina, com o objetivo de praticar a criação de telas, navegação entre páginas e organização de código.
